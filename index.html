Argus

An agentic investment research system that answers questions over your documents and holdings, and refuses to say anything its sources don't support.

  • Research and Critic agents work in a loop. The Critic rejects any claim whose citation does not actually back it up.
  • Allocation, cash planning, and rebalancing run in deterministic Python, so the model explains verified numbers instead of inventing them.
  • Brokerage access goes through read-only MCP tools. Long research jobs run on Redis-backed workers on AWS EKS, separate from the API.

PaymentsMar – Jul 2026Built with Claude Code

PayNova

An escrow payment service where every balance can be rebuilt from its ledger entries, and a retried request never charges twice.

  • Append-only double-entry ledger in PostgreSQL, with automated reconciliation that catches any drift.
  • Idempotency keys stored in the same transaction, compare-and-set state transitions, and ordered row locking keep concurrent retries safe.
  • A transactional outbox with a lease-based retry worker delivers webhooks even after a crash. Verified with JUnit and Testcontainers against real PostgreSQL.

Stack · Java · Spring Boot · PostgreSQL · REST APIs · JUnit · Testcontainers · Docker

Multimodal Notification Router

Sorts incoming text, image, and voice messages into notify, digest, or mute, and treats a wrongly muted message as a trust failure.

  • Reached 90% accuracy with zero wrong mutes on a leave-one-out evaluation.
  • Ranks context by sender relationship, engagement, recency, and Jaccard similarity, and requires schema-validated message-ID citations for every decision.
  • Kafka ingestion and a Redis cache absorb bursts. When rate limits hit, adaptive retries with idempotent replay brought every failed request back to a valid output.

Stack · Python · Gemini · Kafka · Redis
